# tests/ (ponta a ponta)

Testes que cobrem o aplicativo inteiro — Electron + backend + frontend juntos, simulando o uso real de um funcionário processando um lote de PDFs até a planilha final.

Testes unitários e de integração de cada camada isolada ficam dentro do próprio subprojeto (`backend/tests/`, testes de componente em `frontend/web/`).
